# Starter token exports

These files are generated from `templates/DESIGN.md`. They show the export mappings for the example starter. They are not developer selections for a project.

- `starter.tokens.css`: CSS custom properties.
- `starter.tokens.json`: DTCG 2025.10 token data.
- `starter.tailwind.css`: CSS variables and Tailwind v4 theme mappings.
- Each `.report.json` file records the mapping and omitted metadata.

Regenerate with the bundled CLI `export` command after template or exporter changes. Use `--force` only for these generated example files.
