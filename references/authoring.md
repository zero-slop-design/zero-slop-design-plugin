# Skill language

Use ASD-STE100 Issue 9 for skill text.
This instruction includes descriptions, procedures, agent prompts, and other skill instructions.

## Procedure

1. Read the ASD-STE100 standard and dictionary.
2. Use approved words with their approved meanings and parts of speech.
3. Use the specified technical nouns for interface and software items.
4. Use an approved general verb when it gives the operation correctly.
5. Write one instruction in each procedure sentence.
6. Keep each procedure sentence to 20 words or less.
7. Keep each descriptive sentence to 25 words or less.
8. Keep each paragraph to 6 sentences or less.
9. Use the active voice for instructions.
10. Use the same name for each item.
11. Do a language check of the authored text.
12. Record the language inspection date and inspection area.

Do not change code, paths, identifiers, or standard names for a word check.
A technical term list does not give approval for incorrect general language.
The language tool checks selected language conditions.
A dictionary word match does not show correct grammar or word meaning.
Do not include the ASD-STE100 dictionary in this plugin.

## Source data

Get the standard from [ASD](https://www.asd-ste100.org/STE_downloads.html).
Read [Technical terms](technical-terms.md) for project terminology.
