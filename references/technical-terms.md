# Technical terms

Use the project terms in [the term data](technical-terms.json).
The data gives each term, part of speech, category, and meaning.
These meanings are project data.
They do not include the ASD-STE100 dictionary.

Use each term only for its specified meaning and part of speech.
Use an approved general verb when it gives the operation correctly.
Do not use a technical noun as a verb.
Keep the same term for the same item.
A plural noun or approved verb form keeps the same meaning.

The `software` and `interface design` categories contain terms for software items and interface functions.
The `language and documents` category contains terms for skill instructions and writing checks.
The `data processing` category contains technical verbs for software operations.
Read `references/authoring.md` before a term change.
