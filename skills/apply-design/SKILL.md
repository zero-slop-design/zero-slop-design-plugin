# Interface implementation

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Use the design file to make the specified interface changes.

## Input

- Design file and target interface paths.
- Specified interface changes.
- Project components, assets, and style sources.

## Procedure

1. Read the design file and project instructions.
2. Find applicable tokens, components, and assets.
3. Compare the specified task with unresolved design items.
4. Get a developer decision for an unresolved item that prevents the task.
5. Use the project token source and component system.
6. Make the specified interface changes.
7. Keep other design selections.
8. Include the applicable interaction states and responsive behavior.
9. Include keyboard operation and reduced motion behavior.
10. Do only the interface checks with developer approval.
11. Show changed paths, design mappings, and remaining checks.

## Output

- Interface changes mapped to the design file.

## Completed task

- The report identifies the tokens and components used.
- The report gives the inspection area.
- Do not show behavior as correct without measured data.
