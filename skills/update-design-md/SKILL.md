# Design file changes

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Change the specified design data and keep other selections.

## Input

- Target design file.
- Specified changes.
- Project instructions and related token sources.

## Procedure

1. Read the file and the specified changes.
2. Record the design data before the change.
3. Find related tokens, body instructions, and applicable modes.
4. Get a developer decision if the new instructions are different from selections to keep.
5. Change the specified values and their related instructions.
6. Keep other design selections.
7. Change source data and unresolved items.
8. Set the document inspection status to `draft`.
9. Do the document checks from the procedure.
10. Compare the file with the recorded data.
11. Show the changed paths and related interface work.

## Output

- A changed design file and a change report.

## Completed task

- The change report divides specified changes from related changes.
- Each changed selection has source data.
