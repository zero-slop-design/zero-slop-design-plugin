# Accessibility inspection

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Find accessibility defects in the specified inspection area.

## Input

- Design file or interface sources.
- Applicable accessibility standard and level.
- Inspection routes, states, viewports, and tools.

## Procedure

1. Read the design data and specified accessibility target.
2. Record if the inspection includes the document, source code, or an interface in operation.
3. Read the applicable accessibility standard before measured data.
4. Examine text and nontext contrast against backgrounds in operation.
5. Examine labels, names, headings, and status messages.
6. Examine keyboard access, focus visibility, and focus sequence.
7. Examine target size, reflow, zoom, and reduced motion behavior.
8. Use available software tools only for approved checks.
9. Record each defect with source data and its standard criterion.
10. Divide measured results from items for which manual inspection is necessary.
11. Show the inspection area, defects, and missing measured data.

## Output

- An accessibility report with criteria, source data, and inspection area.

## Completed task

- Each defect has an applicable criterion.
- The report does not show interface conformance through document checks.
