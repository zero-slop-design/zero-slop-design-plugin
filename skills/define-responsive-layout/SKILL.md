# Responsive layout data

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Set layout data across the target viewport range.

## Input

- Design file or design brief.
- Content structure and developer selections.
- Target viewport range and interface routes.

## Procedure

1. Read the content structure and target viewport range.
2. Record content sequence and primary interface actions.
3. Set content limits and spacing tokens.
4. Find widths where a different layout is necessary for the content.
5. Make breakpoint tokens for these conditions.
6. Set navigation, column, and container behavior at each breakpoint.
7. Set long text, empty content, and large data behavior.
8. Keep the reading sequence and keyboard sequence the same.
9. Record necessary horizontal scrolling for applicable content.
10. Change only layout data and related instructions.
11. Do the document checks from the procedure.

## Output

- Layout limits, breakpoints, spacing, and responsive instructions.

## Completed task

- Each breakpoint has a content condition.
- The instructions include widths between the example viewports.
