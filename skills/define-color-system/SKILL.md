# Color data

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Set color roles and applicable interface modes.

## Input

- Design file or design brief.
- Developer color selections.
- Applicable modes and component states.

## Procedure

1. Read the color selections and interface functions.
2. Make role tokens for surfaces, text, interface actions, and status indicators.
3. Make the necessary primary and surface pairs.
4. Record each foreground and background pair.
5. Measure contrast for opaque color pairs.
6. Measure alpha colors against the surface in operation.
7. Keep a text or shape status indicator with each status color.
8. Make mode overrides with the same color keys.
9. Examine hover, focus, error, and disabled states.
10. Change only color data and related instructions.
11. Do the document checks from the procedure.

## Output

- Color tokens, mode overrides, and contrast data.

## Completed task

- Each token has a function.
- The report includes token contrast data and the accessibility inspection area.
