# Design extraction

Read [Procedure data](../../references/procedure.md) before the task.
Read [Design format](../../references/design-format.md) for document changes.
Read [Technical terms](../../references/technical-terms.md) for skill language.

## Task

Make a design file from available interface data.

## Input

- Source paths, interface URL, or supplied images.
- Target file path.
- Source conditions and project instructions.

## Procedure

1. Read the supplied sources and project instructions.
2. Record source paths or URLs and the source date.
3. Find colors, typography, spacing, shapes, components, and states in the source data.
4. Use computed styles when an interface is available.
5. Compare items of the same type before you make a token.
6. Record each source location with the related item.
7. Mark image measured data as estimates.
8. Do not show an estimate as a measured value.
9. Record interface states and responsive conditions that the source does not show as `unresolved`.
10. Map the data to the design format.
11. Set the source method to `generated` or `hybrid`.
12. Write the target file.
13. Do the document checks from the procedure.

## Output

- A DESIGN.md file and source data for its selections.

## Completed task

- Each source selection has a source location or an estimate label.
- Source data and missing states are clear.
